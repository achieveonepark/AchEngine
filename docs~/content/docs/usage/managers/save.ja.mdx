---
title: "SaveManager と保存システム"
---

`SaveManager` は保存・読み込み・削除を `ISaveService` の背後へ抽象化します。ローカル実装を Firestore / AWS / Cloudflare D1 に交換してもゲームコードを変更せずに済みます。

```csharp
builder.Register<PlayerManager>();
builder.Register<ISaveService, LocalSaveService>();
builder.Register<SaveManager>();

var service = ServiceLocator.Resolve<ISaveService>();
service.Configure();
var save = ServiceLocator.Resolve<SaveManager>();
await save.SaveAsync();
var loaded = await save.LoadAsync();
await save.DeleteAsync();
```

暗号化キーとバージョンは、QuickSave の Data Protector 依存関係を導入して `USE_ENCRYPT` が有効な場合だけ指定できます。

```csharp
service.Configure(encryptionKey: "myKey12345678!", version: 1);
```

キーは Data Protector の要件を満たす必要があり、バージョンは保存ファイルを区別します。Data Protector がない状態で空でないキーまたは 0 以外のバージョンを渡すと `InvalidOperationException` が発生します。`IsExist` は設定・保存・読み込み・削除時に更新されます。カスタムバックエンドは `ISaveService` を実装して登録します。

<Callout type="warning" title="コンテナ型の変更">

`PlayerManager` は各コンテナの DataKey、アセンブリ修飾型名、Newtonsoft.Json payload を MemoryPack レコードへ保存します。型名またはアセンブリ名を変更すると旧データは `InvalidDataException` になるため、変更前に移行処理または互換型を用意してください。

</Callout>
