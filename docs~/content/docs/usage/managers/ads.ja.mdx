---
title: "AdsManager"
description: "Unity Ads の初期化、全画面・リワード・バナー広告とメディエーション切り替え"
---

`AdsManager` は Unity Ads Legacy 4.16.4 を標準プロバイダーとして、全画面、リワード、バナー広告を
ロード・表示します。`com.unity.ads` は AchEngine 1.3.2 の依存関係なので、パッケージ追加時に Package
Manager が一緒に解決します。`AchManagerInstaller` は `AdsManager` も自動登録します。

実際の配信には Unity Dashboard の Android/iOS ゲーム ID と広告ユニット ID が必要です。Editor は
Android ゲーム ID を使います。`testMode` は開発時だけ `true` にしてください。

## クイック設定

ブートストラップで初期化前に一度設定します。VContainer では注入された `AdsManager` に同じ呼び出しを
行います。

```csharp
var ads = ServiceLocator.Resolve<AdsManager>();

ads.Configure(new AdsConfiguration(
    androidGameId: "Android game ID",
    iosGameId: "iOS game ID",
    interstitialAdUnitId: "Interstitial_Android",
    rewardedAdUnitId: "Rewarded_Android",
    bannerAdUnitId: "Banner_Android",
    testMode: true));

ads.InitializationFailed += message => Debug.LogError(message);

await ads.Initialize();
await ads.LoadInterstitialAsync();
await ads.LoadRewardedAsync();
```

Android と iOS の広告ユニット ID が異なる場合は、各プラットフォームのブートストラップで対応する
`AdsConfiguration` を作成します。`Configure()` は初期化開始前にのみ呼び出せます。

## 全画面・リワード広告

表示前にロードし、全画面広告は表示を試行した後で再ロードします。リワードは
`ShouldGrantReward` が `true` の時だけ付与してください。スキップ・失敗時には付与しません。

```csharp
var result = await ads.ShowRewardedAsync();

if (result.ShouldGrantReward)
    GrantCoinsToPlayer();
else if (!result.IsSuccess)
    Debug.LogWarning(result.Message);

await ads.LoadRewardedAsync();
```

## バナー広告

標準 Unity Ads プロバイダーは画面下中央にバナーを表示します。`ShowBannerAsync()` の成功は SDK に
表示要求を渡したことを示すだけで、インプレッションを意味しません。

```csharp
await ads.LoadBannerAsync();
await ads.ShowBannerAsync();
ads.HideBanner();
```

## メディエーション

標準プロバイダーは小さな Unity Ads Legacy 統合です。複数ネットワークの競争を行う新規ライブ運用では、
以下のメディエーションを使えます。

| 選択肢 | 適するケース | AchEngine への接続 |
| --- | --- | --- |
| Unity LevelPlay | Unity Ads 中心の運用と Unity の現行メディエーション | LevelPlay SDK を `IAdsProvider` でラップします。 |
| AppLovin MAX | 高度な収益化・入札ツールと広いネットワーク運用 | MAX Unity SDK の `IAdsProvider` を実装します。 |
| Google AdMob / Google Ad Manager | Google 広告、Firebase、GAM レポートを利用中 | AdMob Unity SDK と現在対応の Unity Ads アダプターをラップします。 |
| Digital Turbine FairBid など | その提供元の契約・運用ツールを利用中 | 同じインターフェースで Unity SDK をラップします。 |

アダプター提供、入札対応、最低 Android/iOS SDK、プライバシー・ATT 要件は頻繁に変わります。導入前に
選択したメディエーションの最新 Unity Ads アダプターとプラットフォーム要件を確認してください。

```csharp
var ads = AdsManager.Create(new MyLevelPlayAdsProvider());
```

`IAdsProvider` は初期化、ロード・表示、バナー非表示だけを定義します。アダプターはコールバックを
`AdsLoadResult`/`AdsShowResult` に変換し、リワード広告が最後まで完了した時だけ `Completed` を返します。
同一セッションで Unity Ads Legacy と LevelPlay を同時に初期化しないでください。

## API

| メンバー | 説明 |
| --- | --- |
| `Configure(configuration)` | 初期化前にゲーム ID と広告ユニット ID を設定します。 |
| `Initialize()` | 現在のプラットフォームのゲーム ID で初期化します。 |
| `LoadInterstitialAsync()` / `LoadRewardedAsync()` / `LoadBannerAsync()` | 表示用に広告をロードします。 |
| `ShowInterstitialAsync()` / `ShowRewardedAsync()` / `ShowBannerAsync()` | ロード済み広告を表示して結果を返します。 |
| `HideBanner()` | 表示中のバナーを隠します。 |
| `IsLoaded(placement)` | 広告の表示準備状態を確認します。 |
| `AdsShowResult.ShouldGrantReward` | 完了したリワード広告の場合だけ `true` です。 |
