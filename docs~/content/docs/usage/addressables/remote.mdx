## 원격 콘텐츠 설정

원격 번들의 실제 빌드·로드 경로는 Unity **Addressables Groups**의 Profile과 그룹 스키마에서 설정합니다. 먼저 원격으로 배포할 그룹의 Build Path와 Load Path를 Remote로 지정하고, 콘텐츠를 빌드한 뒤 생성된 파일을 해당 경로에 배포하세요.

**Project Settings › AchEngine › Addressables › 원격 콘텐츠**에서는 배포 환경 정보를 함께 관리할 수 있습니다.

| 항목 | 설명 |
|---|---|
| **클라우드 공급자** | AWS S3, Google Cloud Storage 또는 Custom |
| **버킷 이름 / 리전** | S3·GCS 기본 URL 생성에 사용하는 값 |
| **Catalog URL** | 자동 생성 URL 대신 사용할 카탈로그 URL |
| **Bundle URL** | 자동 생성 URL 대신 사용할 번들 URL |

## 권장 흐름

1. 원격 그룹과 다운로드 대상 라벨을 Unity Addressables에 설정합니다.
2. **AchEngine › Addressables › Build Content**로 콘텐츠를 빌드합니다.
3. 생성된 카탈로그와 번들을 원격 Load Path에 배포합니다.
4. 런타임에서 카탈로그를 확인하고, 필요한 라벨의 종속성을 다운로드합니다.

## 카탈로그 업데이트 확인

```csharp
using AchEngine.Assets;

// 새 카탈로그가 있으면 업데이트
var catalogs = await AddressableManager.CheckForCatalogUpdatesAsync();
if (catalogs.Count > 0)
{
    await AddressableManager.UpdateCatalogsAsync(catalogs);
}
```

카탈로그 업데이트가 성공하면 이전 위치 메타데이터 캐시는 자동으로 비워집니다. 이미 로드해 둔 에셋 캐시는 유지되므로, 변경된 에셋을 다시 받아야 하면 해당 주소를 `Release`한 뒤 다시 로드하세요.

초기화·다운로드 크기 조회·종속성 다운로드·카탈로그 확인·업데이트 작업에 사용하는 임시 핸들은 작업 완료 후 자동으로 해제됩니다. 업데이트 후에도 사용 중인 에셋은 캐시에 남아 있으므로, 더 이상 필요하지 않은 주소만 명시적으로 `Release`하세요.

## 원격 에셋 크기 확인 후 다운로드

```csharp
using AchEngine.Assets;

long size = await AddressableManager.GetDownloadSizeAsync("remote_assets");
if (size > 0)
{
    // 사용자 확인 후 다운로드하고 진행률 표시
    await AddressableManager.DownloadDependenciesAsync(
        "remote_assets",
        progress => progressBar.value = progress.Percent);
}
```

`GetDownloadSizeAsync`의 반환값은 바이트 단위이며, 이미 캐시된 종속성은 크기에 포함되지 않습니다.

## 빌드 설정

**Project Settings › AchEngine › Addressables** 또는 **AchEngine › Addressables** 메뉴에서 콘텐츠를 빌드합니다.

| 항목 | 설명 |
|---|---|
| **Build Content** | 현재 Addressables 설정으로 콘텐츠를 빌드 |
| **Clean Build** | 기존 빌드 결과를 정리한 뒤 콘텐츠를 다시 빌드 |
| **Re-scan Watched Folders** | 감시 폴더를 다시 스캔해 Addressable 항목을 갱신 |

<Callout type="info" title="개발 중 Fast Mode 사용">

개발 중에는 Play Mode를 **Use Asset Database (Fast Mode)** 로 설정하면
빌드 없이 에셋을 직접 참조해 빠르게 반복 작업할 수 있습니다.

</Callout>
