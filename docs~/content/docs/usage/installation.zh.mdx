## UPM — Git URL（推荐）

在 Unity **Window › Package Manager** 中选择 **+ › Add package from git URL...**，输入：

```
https://github.com/achieveonepark/AchEngine.git
```

需要固定版本时追加 `#1.0.0` 等标签。

## `manifest.json`

```json
{
  "dependencies": {
    "com.achieve.engine": "https://github.com/achieveonepark/AchEngine.git"
  }
}
```

## 可选包

| 包 | ID | 启用功能 |
|---|---|---|
| VContainer | `jp.hadashikick.vcontainer` | DI 容器 |
| MemoryPack | `com.cysharp.memorypack` | 表格二进制序列化以及 QuickSave 的必需依赖 |
| QuickSave 1.0.3+ | `com.achieve.quick-save` | `LocalSaveService`（同时需要 MemoryPack） |
| Addressables | `com.unity.addressables` | AddressableManager |
| Input System | `com.unity.inputsystem` | AchMover、InputManager 与 UI 的新输入路径 |
| R3 | `com.cysharp.r3` | UIBindingManager |
| UniTask | `com.cysharp.unitask` | AchTask 的 UniTask 后端 |

VContainer 需要配置 OpenUPM 注册表；MemoryPack 和 R3 请参考各自的 GitHub 安装指南。使用 `LocalSaveService` 时，请先安装 MemoryPack，再从 `https://github.com/achieveonepark/QuickSave.git` 安装 QuickSave 1.0.3 或更高版本。

## 验证

Unity Console 没有包错误，并且出现 **Window › AchEngine › AchEngine Info** 即表示安装完成。
