title: "AchDebugConsole"
---

`AchDebugConsole` 是显示在 Android/iOS 原生 UI 层的调试控制台，编辑器中使用 IMGUI 回退。

## 概览

通过 `Application.logMessageReceivedThreaded` 自动接收 Log、Warning、Error、Exception 和 Assert，最多保留 500 条日志，并在 UI 线程分发。

## 平台行为

- **Android**：附加在 Unity Activity 内的可拖动原生 View，不需要 `SYSTEM_ALERT_WINDOW`。
- **iOS**：`UIWindowLevelAlert + 100` 的独立窗口，不需要额外权限。
- **Editor**：`Show` / `Hide` 切换内部状态；要在 Game View 显示覆盖层，请在 `OnGUI()` 调用 `DrawEditorGUI()`。

## API

```csharp
AchDebugConsole.Show();
AchDebugConsole.Hide();
AchDebugConsole.Toggle();
AchDebugConsole.Clear();
bool visible = AchDebugConsole.IsVisible;
```

Android 会先将线程日志放入队列，再由 Unity 主线程每帧最多通过 JNI 传递 50 条，以避免递归错误与明显帧尖峰；不需要额外权限。
