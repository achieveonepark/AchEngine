---
title: "UIBindingManager *(ACHENGINE_R3)*"
---

R3 の `Subject<T>` を使う型安全な pub/sub バスです。`com.cysharp.r3` がある場合のみ有効です。

```csharp
public struct GoldChangedMessage { public int Amount; }
UIBindingManager.Publish(new GoldChangedMessage { Amount = 500 });

private IDisposable _subscription;
private void OnEnable()
    => _subscription = UIBindingManager.Subscribe<GoldChangedMessage>(m => goldLabel.text = m.Amount.ToString());
private void OnDisable() => _subscription?.Dispose();
```

`Contains<T>()` で Subject の有無を確認し、`ClearAll()` で全 Subject を削除できます。
