## UPM — Git URL（推奨）

Unity の **Window › Package Manager** で **+ › Add package from git URL...** を選び、次を入力します。

```
https://github.com/achieveonepark/AchEngine.git
```

バージョンを固定する場合は `#1.0.0` のようにタグを付けます。

## `manifest.json`

```json
{
  "dependencies": {
    "com.achieve.engine": "https://github.com/achieveonepark/AchEngine.git"
  }
}
```

## オプションパッケージ

| パッケージ | ID | 有効になる機能 |
|---|---|---|
| VContainer | `jp.hadashikick.vcontainer` | DI コンテナ |
| MemoryPack | `com.cysharp.memorypack` | テーブルのバイナリ化と QuickSave の必須依存関係 |
| QuickSave 1.0.3+ | `com.achieve.quick-save` | `LocalSaveService`（MemoryPack も必要） |
| Addressables | `com.unity.addressables` | AddressableManager |
| Input System | `com.unity.inputsystem` | AchMover・InputManager・UI の新入力経路 |
| R3 | `com.cysharp.r3` | UIBindingManager |
| UniTask | `com.cysharp.unitask` | AchTask の UniTask バックエンド |

VContainer は OpenUPM レジストリへ追加し、MemoryPack と R3 は各 GitHub のインストールガイドを参照してください。`LocalSaveService` を使う場合は MemoryPack を先に導入し、その後 `https://github.com/achieveonepark/QuickSave.git` から QuickSave 1.0.3 以降をインストールします。

## 確認

Unity Console にエラーがなく、**Window › AchEngine › AchEngine Info** が表示されれば完了です。
