---
title: "AchMover"
---

`AchMover` is a plug-in 2D character movement component. It does **not** use `Rigidbody2D`; it implements Move-and-Slide collision, gravity, slopes, stairs, and ground snapping directly.

## Usage

Add `AchMover` to the character; Unity adds its required `CapsuleCollider2D`. Use the built-in input, assign `InputProvider`, or call the public movement methods.

## Inspector

### Movement

Configure `MoveSpeed`, `JumpForce`, and Platformer or TopDown mode.

### Physics

Configure gravity scale, fall multiplier, and terminal velocity. Collision follows Unity's 2D layer collision matrix.

### Slopes & stairs

Set `MaxSlopeAngle` and `StepHeight` to control walkable slopes and automatic stair climbing.

### Control

Use `Movable` to enable player input and `FlipSprite` to control horizontal flipping.

## Built-in collision system

Each frame the component:

1. Combines input, gravity, and jump velocity.
2. Corrects initial penetration before movement.
3. Casts the capsule and slides along collision surfaces, up to four iterations.
4. Steps over ledges within `StepHeight`.
5. Casts below the collider and marks the character grounded when the surface is within `MaxSlopeAngle`.
6. Snaps to the ground while descending slopes.

AchMover collision uses cast results rather than Unity physics callbacks. For gameplay hits or trigger zones, use `Physics2D` queries or a separate transform-based detector.

## State properties

```csharp
var mover = GetComponent<AchMover>();
bool grounded = mover.IsGrounded;
Vector2 velocity = mover.Velocity;
```

## Joystick or custom input

```csharp
mover.InputProvider = () => new Vector2(horizontal, vertical);
// Restore the built-in keyboard/gamepad input.
mover.InputProvider = null;
```

## Code-control API

```csharp
mover.Jump();
mover.Teleport(new Vector2(10f, 0f));
mover.SetVelocity(new Vector2(-5f, 4f));
mover.AddForce(new Vector2(3f, 2f), ForceMode2D.Impulse);
mover.AddForce(Vector2.right * 20f, ForceMode2D.Force);
mover.Stop();
```

### Knockback

```csharp
private void OnHit(Vector2 direction)
{
    var mover = GetComponent<AchMover>();
    mover.Movable = false;
    mover.SetVelocity(direction.normalized * 8f);
}
```

## Combining `UseGravity`

Disable `UseGravity` when another system owns vertical movement. Re-enable it before returning control to AchMover.

## `AchFollower` — AI following

`AchFollower` is a standalone target-following component. It does not require `AchMover`.

```csharp
var follower = GetComponent<AchFollower>();
follower.SetTarget(playerTransform);
follower.ClearTarget();
```

## `AchProjectile` — projectiles

`AchProjectile` supports straight and homing movement without `Rigidbody2D`. Configure its speed, direction, turn speed, and projectile type, then set the target for a homing shot. Passing `Vector2.zero` to `Launch` uses `Vector2.right`.

```csharp
var projectile = Instantiate(projectilePrefab);
projectile.Launch(direction);
projectile.SetTarget(target);
```

`SetVelocity`, `Teleport`, `Launch`, and the numeric inspector settings reject non-finite values so invalid input cannot poison later movement calculations.
