title: "AchDebugConsole"
---

`AchDebugConsole` は Android・iOS のネイティブ UI レイヤーに表示するデバッグコンソールです。Editor では IMGUI フォールバックを使います。

## 概要

`Application.logMessageReceivedThreaded` から Log、Warning、Error、Exception、Assert を自動収集します。最大 500 件のリングバッファで、UI スレッドへディスパッチします。

## プラットフォーム

- **Android**: Unity Activity 内に追加されるドラッグ可能なネイティブ View。`SYSTEM_ALERT_WINDOW` は不要です。
- **iOS**: `UIWindowLevelAlert + 100` の独立した `UIWindow`。追加権限は不要です。
- **Editor**: `Show` / `Hide` は内部状態を切り替えます。Game View には `DrawEditorGUI()` を `OnGUI()` から呼び出します。

## API

```csharp
AchDebugConsole.Show();
AchDebugConsole.Hide();
AchDebugConsole.Toggle();
AchDebugConsole.Clear();
bool visible = AchDebugConsole.IsVisible;
```

Android ではスレッドログをキューへ保存し、Unity メインスレッドから 1 フレーム最大 50 件ずつ JNI へ渡すことで再帰エラーと大きなフレームスパイクを防ぎます。追加権限は不要です。
