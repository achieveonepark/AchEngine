## UPM — install from a Git URL (recommended)

Open **Window › Package Manager** in the Unity Editor, choose **+ › Add package from git URL...**, and enter:

```
https://github.com/achieveonepark/AchEngine.git
```

Pin a specific version by adding a tag:

```
https://github.com/achieveonepark/AchEngine.git#1.0.0
```

## Install through `manifest.json`

Add the package directly to `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.achieve.engine": "https://github.com/achieveonepark/AchEngine.git"
  }
}
```

## Optional packages

AchEngine supports the following optional packages. Installing one enables its feature automatically. Check the status in **Window › AchEngine › AchEngine Info**.

| Package | Package ID | Enabled features |
|---|---|---|
| VContainer | `jp.hadashikick.vcontainer` | DI container (`AchEngineScope`, `ServiceLocator`) |
| MemoryPack | `com.cysharp.memorypack` | Binary table serialization and the QuickSave dependency |
| QuickSave 1.0.3+ | `com.achieve.quick-save` | `LocalSaveService` (`USE_QUICK_SAVE`; MemoryPack is also required) |
| Addressables | `com.unity.addressables` | `AddressableManager`, remote content |
| Input System | `com.unity.inputsystem` | New input path for AchMover, InputManager, and UI |
| R3 | `com.cysharp.r3` | `UIBindingManager` reactive pub/sub |
| UniTask | `com.cysharp.unitask` | UniTask backend for AchTask |

### Install VContainer manually

Add the registry and dependency to `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "package.openupm.com",
      "url": "https://package.openupm.com",
      "scopes": ["jp.hadashikick.vcontainer"]
    }
  ],
  "dependencies": {
    "jp.hadashikick.vcontainer": "1.15.0"
  }
}
```

For MemoryPack, see the [MemoryPack installation guide](https://github.com/Cysharp/MemoryPack). To use `LocalSaveService`, install MemoryPack first and then install QuickSave 1.0.3 or later from `https://github.com/achieveonepark/QuickSave.git`. For R3, see the [R3 repository](https://github.com/Cysharp/R3).

## Verify the installation

The Unity Console should contain no package errors, and **Window › AchEngine › AchEngine Info** should be available. The window shows the package and feature status at a glance.
