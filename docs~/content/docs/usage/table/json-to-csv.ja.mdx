---
title: "JSON → CSV エクスポート"
---

**AchEngine › Table JSON to CSV** を開きます。配列または `items` などの配列プロパティを持つ JSON を変換できます。

```json
[
  { "Id": 101, "Name": "Iron Sword", "Price": 500 },
  { "Id": 102, "Name": "Magic Wand", "Price": 1200 }
]
```

```csv
Id,Name,Price
101,Iron Sword,500
102,Magic Wand,1200
```

**Select JSON** と **Select CSV Location** で単一ファイルを変換します。フォルダー単位では入力・出力フォルダーを選び、必要なら **Include Subfolders** を有効にして **Convert Folder** を押します。
