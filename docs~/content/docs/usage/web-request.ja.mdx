---
title: "HttpLink"
---

`HttpLink` は UnityWebRequest をビルダーパターンでラップし、GET/POST、JSON、ヘッダー、タイムアウトを扱います。

```csharp
var result = await new HttpLink.Builder()
    .SetUrl("https://api.example.com/users/1")
    .AddHeader("Authorization", "Bearer token123")
    .SetTimeout(10)
    .GetAsync<UserData>();

bool success = await new HttpLink.Builder()
    .SetUrl("https://api.example.com/login")
    .SetJsonBody(json)
    .PostAsync();
```

`Build().SendAsync()` では `Success`、`Result`、`ReceiveDataString`、`ReceiveData`、`DownloadSize`、`DownloadProgress` を直接確認できます。直接使用する `HttpLink` は `IDisposable` なので `using var link = await ...SendAsync()` で解放します。`GetAsync<T>()` と `PostAsync()` は自動解放します。`SendAsync(cancellationToken)` はキャンセルに対応します。`SetMethod` を省略すると JSON body ありは POST、なしは GET になります。JSON は Newtonsoft.Json を使います。
