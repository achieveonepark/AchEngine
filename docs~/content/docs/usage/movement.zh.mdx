---
title: "AchMover"
---

`AchMover` 是即插即用的 2D 角色移动组件。**不使用 Rigidbody2D**，直接实现碰撞滑动、重力、斜坡、台阶和地面吸附。

## 基本用法

为角色添加 `AchMover`，Unity 会同时添加所需的 `CapsuleCollider2D`。可使用内置输入或 `InputProvider`。

```csharp
var mover = GetComponent<AchMover>();
mover.InputProvider = () => new Vector2(horizontal, vertical);
mover.Jump();
bool grounded = mover.IsGrounded;
```

通过 `MaxSlopeAngle` 和 `StepHeight` 配置可行走斜坡与自动上台阶。每帧执行速度计算、移动前穿透修正、最多四次 Move-and-Slide、台阶处理、地面检测和吸附。

```csharp
mover.Teleport(new Vector2(10f, 0f));
mover.SetVelocity(knockbackDirection * 8f);
mover.AddForce(Vector2.right * 20f, ForceMode2D.Force);
mover.Stop();
```

由其他系统负责垂直移动时禁用 `UseGravity`。

## `AchFollower` 与 `AchProjectile`

`AddForce` 以质量 1 计算；`Impulse` 立即生效，`Force` 会乘以 `Time.fixedDeltaTime`。`AchFollower` 是独立的目标跟随组件，不依赖 `AchMover`。`AchProjectile` 不使用 Rigidbody2D，支持直线和追踪移动；`Launch(Vector2.zero)` 会使用向右方向。

```csharp
GetComponent<AchFollower>().SetTarget(playerTransform);
projectile.Launch(direction);
projectile.SetTarget(target);
```

数值配置与移动 API 会拒绝 NaN/Infinity。

AchMover 碰撞使用投射结果，而不是 Unity 物理回调。游戏命中或触发区域请使用 `Physics2D` 查询，或独立的 transform 检测组件。
